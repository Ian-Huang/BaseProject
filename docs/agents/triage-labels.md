# 分類標籤 (Triage Labels)

這些技能會使用五個標準的分類角色。本檔案將這些角色對應到此專案問題追蹤系統中實際使用的標籤字串。

| mattpocock/skills 中的標籤 | 追蹤系統中的標籤 | 意義                                       |
| -------------------------- | ---------------- | ------------------------------------------ |
| `needs-triage`             | `needs-triage`   | 維護者需要評估此 Issue                     |
| `needs-info`               | `needs-info`     | 正在等待回報者提供更多資訊                 |
| `ready-for-agent`          | `ready-for-agent`| 規格已完整，準備好交由離線 (AFK) Agent 處理|
| `ready-for-human`          | `ready-for-human`| 需要由人類實作                             |
| `wontfix`                  | `wontfix`        | 將不會處理                                 |

當技能提到某個角色 (例如「套用 AFK-ready 分類標籤」) 時，請使用此表格中對應的標籤字串。

您可以編輯右側的欄位，以符合您實際使用的任何詞彙。
